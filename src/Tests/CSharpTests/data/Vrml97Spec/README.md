# Vrml97 specification example scenes

Downloaded 2026-07-31 from the Web3D Consortium example archive:
https://www.web3d.org/x3d/content/examples/Basic/Vrml97Specification/

These are the annex D examples of the Vrml97 specification (ISO/IEC 14772-1:1997),
plus the Chopper/Rotor/RefractiveMaterial scenes of the same directory.
`exampleD_5.wrl` comes from the `originals` subdirectory.

## What they cover

They are a smoke-test corpus for the loader as a whole, NOT extra coverage for the IndexedLineSet work: **none of these scenes contains an IndexedLineSet**.
The nodes cover (by frequency):

    Shape 45, Transform 44, Appearance 32, Material 29, WorldInfo 20, Sphere 14,
    Script 13, Box 9, Group 7, Viewpoint 6, TimeSensor 6, Cylinder 6,
    TouchSensor 5, Cone 5, Anchor 5, Extrusion 4, Text 3, ProximitySensor 3,
    PositionInterpolator 3, OrientationInterpolator 3, NavigationInfo 3,
    FontStyle 3, Color 3, Sound 2, PointSet 2, LOD 2, Inline 2,
    DirectionalLight 2, Coordinate 2, AudioClip 2, TextureCoordinate 1,
    PixelTexture 1, Normal 1, IndexedFaceSet 1, ColorInterpolator 1,
    plus PROTOs (Chopper, Rotor, Shuttle, Pendulum, RefractiveMaterial, TwoColorTable)
